# AI-Native Developer Journey

## Mission
Become a job-ready AI-native software developer who can understand fundamentals, build software, use AI effectively, build AI applications and agents, automate workflows, deploy production systems, debug software, and explain projects in interviews.

## Four-Month Roadmap

### September — Foundation + Python
- Computer fundamentals
- Internet, DNS, HTTP/HTTPS
- Terminal, JSON, environment variables
- Python fundamentals
- Functions, collections, files, exceptions
- OOP
- Git/GitHub basics

### October — Web + Backend + Database
- HTML/CSS/JavaScript
- HTTP and REST APIs
- Python backend
- FastAPI/Flask concepts
- SQL/PostgreSQL
- CRUD
- Authentication/authorization basics
- Testing and API debugging
- Full-stack project

### November — AI Engineering + RAG + Agents + Automation
- LLM fundamentals
- Tokens/context
- Prompt engineering
- Structured outputs
- Tool/function calling
- Embeddings
- RAG
- Agents
- Memory and evaluation
- AI security
- n8n automation

### December — Production + DevOps + Security + System Design
- Docker
- Linux
- CI/CD
- Cloud concepts
- Monitoring/logging
- Security
- System design
- Production-ready projects
- Portfolio and interview preparation

## Learning Loop

**Learn → Practice → Build → Test → Debug → Revise → Document → Commit → Push → Review**

## AI Rule

AI is a mentor and coding collaborator, not a replacement for understanding. Attempt problems yourself first, ask for hints when stuck, review generated code line by line, and periodically work without AI.
